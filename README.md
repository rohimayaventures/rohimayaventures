## Live products

### OrixLink AI — Universal triage and diagnosis intelligence

**[triage.rohimaya.ai](https://triage.rohimaya.ai) · [github.com/rohimayaventures/orixlink](https://github.com/rohimayaventures/orixlink)**

Any symptom, any person, no prior diagnosis required. OrixLink reads who is asking — patient, family member, or clinician — and delivers a structured clinical assessment calibrated to that user’s role, language, and context. The assessment updates dynamically as the conversation continues.

Key decisions: 4-tier urgency system, ranked differential diagnoses with supporting evidence per turn, per-symptom red flag tracking, patient refusal protocol with hours-to-harm escalation, role-adaptive output, 6-language support.

**Stack:** Next.js 16, TypeScript, Tailwind CSS v4, Claude API, Supabase, Vercel

-----

### HealthLiteracy AI — Medical documents in plain language

**[literacy.rohimaya.ai](https://literacy.rohimaya.ai) · [github.com/rohimayaventures/healthliteracy-ai](https://github.com/rohimayaventures/healthliteracy-ai)**

Translates clinical documents into plain language at three reading levels. Supports 12 languages. A reverse-check verification step sends the translation back through Claude before showing it to the patient, catching errors before they reach someone who cannot catch them themselves.

Input methods: PDF upload, voice input, text paste. Output: Supabase-backed shareable URLs per translation.

**Stack:** Next.js 15, TypeScript, Tailwind CSS v4, Claude API, pdf-parse, Supabase, Vercel

## Conversation design work

### ClearChannel by Vestara — Enterprise multi-channel conversational AI

**[clearchannel-vestara.vercel.app](https://clearchannel-vestara.vercel.app)**

A conversational design lab built around Vestara, a fictional enterprise financial services firm. Type or speak any investor utterance and the system generates simultaneous structured outputs for IVR, Chatbot, and Agent Assist — plus a full NLU architecture breakdown showing intent taxonomy, entity schema, training phrases, and confidence thresholds.

Built as a leave-behind artifact for Vanguard’s Conversational Channels UX team. The 11 sample utterances were chosen deliberately — not generic queries, but the edge cases that expose the quality of a conversational system. The bereavement utterance and the market-panic utterance are the ones that reveal whether a designer understands emotional state handling.

Key design decisions: single utterance driving three channel outputs simultaneously, compliance flag detection, channel-appropriate escalation logic, per-channel tone calibration, voice input via OpenAI Whisper with IVR spoken response via OpenAI TTS, NLU architecture card per utterance.

This is what it means to design the full system — not one channel at a time.

**Stack:** Next.js, TypeScript, Tailwind CSS, Claude API, OpenAI Whisper, OpenAI TTS, Vercel
